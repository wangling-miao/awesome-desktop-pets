# Venti Bard

A tiny wind-bard desktop pet inspired by Venti, with teal braids, a green cape, and a bright bard hat.

This package is included as the first gallery sample because it is already compatible with the existing Codex / hatch-pet contract:

- `pet.json`
- `spritesheet.webp`
- 192 x 208 cell
- 1536 x 1872 atlas

## Notes

This is a fan-art style sample package. Before redistributing it publicly, verify that the artwork source and character usage are allowed for your intended use.
